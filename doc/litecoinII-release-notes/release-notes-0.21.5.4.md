LitecoinII 0.21.5.4 Release Notes
====================


LitecoinII has been updated to include the latest fixes and improvements from [Litecoin Core v0.21.5.4](https://github.com/litecoin-project/litecoin/blob/master/doc/litecoin-release-notes/release-notes-0.21.5.4.md).

This update addresses important MWEB-related validation issues and enhances overall network stability.

All users are encouraged to upgrade to the latest version.
